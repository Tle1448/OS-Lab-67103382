1. The Role of the Operating System:
In this mini-project, our Python script simulated the major
responsibilities of an Operating System.
Match the specific code behavior in `ultimate_cluster_os.py` to
the corresponding OS concept you learned throughout the semester:
- File System & Permissions (Lab 9):
[Explain which line of code simulated this and why Workload D
failed]

The code uses os.path.exists(dataset_path) to check if the dataset file exists. Workload D failed because it requested secret_keys.txt, which does not exist. The OS therefore rejected the job before it could run.


- Memory Management (Labs 5/6):
[Explain how the OS prevented Thrashing by using the `while`
loop for RAM allocation]

The while loop checks whether enough RAM is available before allocating memory. If there is not enough RAM, the job waits until other jobs release their memory. This prevents the system from using more RAM than available and helps avoid excessive memory pressure and thrashing.


- Concurrency & Deadlocks (Labs 3/4):
[Explain how the OS sorted the requested GPUs to avoid Circular
Wait deadlocks]

The code uses sorted(req_gpus) before acquiring GPU locks. All jobs therefore request GPUs in the same order, which helps prevent circular wait and reduces the risk of deadlock.
